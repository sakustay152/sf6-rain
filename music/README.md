# music

把你自己合法持有的音频放在这里：

- 支持格式：mp3 / wav / wma / m4a / aac / flac
- 会递归查找子文件夹，可以放多首，默认随机播放
- 文件名里带「雨爱」或「rain love」的歌会被优先选中

**本仓库不附带任何歌曲。**《雨爱》等录音的版权属于原权利人，
请使用你自己合法获得的音频，不要把受版权保护的文件提交到仓库。

---

Put your own legally obtained audio files here. No music is bundled with
this repository. Supported formats: mp3, wav, wma, m4a, aac, flac.
Files whose names contain 「雨爱」 or "rain love" are preferred.
